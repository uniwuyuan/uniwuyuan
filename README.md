### uni station

独立开发 Android 输入法「[半字 · Banzi](https://github.com/uniwuyuan/banzi)」——
纯 Java、自绘键盘、离线联想引擎。

[⬇️ APK](https://github.com/uniwuyuan/banzi/releases/latest) · [🎮 在线试玩](https://uniwuyuan.github.io/banzi/) · [🎛️ 设计台](https://uniwuyuan.github.io/banzi/design-console.html)

---

**在做什么**

- **纯 Java 8** 自绘输入法：键盘 / 候选栏 / 动画全部 `Canvas` 手写，零 Kotlin 核心代码
- **离线联想引擎**：trigram + 时间衰减，held-out `hit@5 9.69%`（基线 2.84%），评测脚本全开源
- **可玩设计台**：浏览器里改键距 / 圆角 / 配色，JSON 契约直接回落到 App
- **隐私分级**：L1 只关记录 / L2 关读取+关云端，可一键全停

**技术栈**

`Java` · `Android InputMethodService` · `Canvas` 自绘 · `离线 NLP` · `sherpa-onnx` · `GitHub Pages`

**顺手在做**

Python 自动化 · 爬虫（Playwright / requests）· Frida 逆向 · 中文平台数据采集

**能接的活**

企业定制输入法 / 小语种键盘 / 键盘 SDK 集成 / 自动化脚本
